# 合租日记 · hezuriji

![验证门](https://github.com/handkerhandker/hezuriji/actions/workflows/gate.yml/badge.svg)

**一群 AI 小人，在合租公寓里自己过日子。你只管围观、刷动态、递纸条。**

《合租日记》是一个都市生活旁观原型：5 个性格迥异的小人（抠门会计、月光骑手、社牛教练、社恐程序员、找工作的应届生）住在同一间公寓，上班、吃饭、唠嗑、请客、交租、求职、摸鱼——全部自己拿主意。你不是玩家，是房东兼老友：刷他们的动态流，翻城市日报，偶尔发条短信轻轻推一把。

**他们听不听你的，看他们自己的心情、钱包和记性。**

## 现在就能玩到的

- 🏙️ **像素小城**：公寓（三间卧室+厨房客厅）、便利店、公司、街道四街区，小人真实走位、过马路、去上班，天色随游戏时间变化
- ⏰ **日子自己走**：10 分钟一步的连续时间，昼夜日程，周五发薪、月底交租
- 💬 **短信系统**：每天 3 条，TA 按状态和性格消化——可能回信，可能已读不回；内心独白去动态流里偷看
- 🧠 **性格是物理约束**：节俭的人根本看不到贵价选项，社恐不会主动约饭（CK3 式特质系统）
- 🌧️ **AI 导演**：太久没戏就悄悄下一场雨
- 📰 **城市日报**：每天一页，谁翘班了、谁请客了、谁找到工作了
- 📈 **指标面板**：动作熵/基尼系数/社交密度/戏剧温度，平衡靠曲线不靠感觉
- 🎮 **三套输入**：键鼠（空格/1/2/R/M/T）、触屏、手柄（十字键+A/B/Start/肩键）
- 📱 **全屏自适应**：桌面三栏、平板两栏、手机单栏+底部标签，刘海屏安全区

## 技术路线：规则打底，AI 可插拔

日常骨架由代码结算（零成本、永不崩）；大模型只负责"有戏的时刻"（社交、冲突、收到短信、日终反思）。接口已留好（`BrainHook`），默认不接 AI 也能完整玩。

- React 19 + TypeScript + Vite + Tailwind，纯前端无服务器
- `src/engine/` 纯 TS 零 DOM 依赖，可 headless 裸跑（30 天退化检查就是这么验的）
- 事件溯源：世界的一切都是追加日志，同种子可精确重放
